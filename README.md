
# 💰 Medical Insurance Cost Prediction

## 📌 Overview

This project focuses on predicting individual medical insurance costs using Machine Learning regression models. The objective is to analyze demographic and health-related factors to estimate healthcare expenses accurately.

The dataset includes features such as age, BMI, number of children, smoking habits, and region.

---

## 🎯 Problem Statement

Insurance companies need to estimate medical costs based on customer profiles.
This project builds predictive models to estimate insurance charges using supervised learning techniques.

---

## 📊 Dataset Features

* Age
* Sex
* BMI
* Number of Children
* Smoker Status
* Region
* Charges (Target Variable)

---

## 🛠 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## ⚙️ Project Workflow

1. Data Cleaning and Preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature Encoding (Categorical Variables)
4. Feature Scaling
5. Model Training using Regression Algorithms
6. Model Evaluation using R² Score and MAE

---

## 🤖 Models Implemented

* Linear Regression
* Random Forest Regressor

---

## 📈 Model Performance

* Evaluated using:

  * R² Score
  * Mean Absolute Error (MAE)

The Random Forest model demonstrated improved predictive performance compared to baseline linear regression.

---

## 📌 Key Insights

* Smoking status significantly increases insurance charges.
* BMI and age show strong correlation with medical cost.
* Tree-based models capture nonlinear patterns better than simple regression.
